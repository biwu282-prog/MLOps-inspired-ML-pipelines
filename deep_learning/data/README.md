# Animals-10 Dataset

Download Animals-10 from Kaggle:

https://www.kaggle.com/datasets/alessiocorrado99/animals10

Extract or arrange the dataset so that each class is represented by one folder:

```text
deep_learning/data/animals10/
  butterfly/
  cat/
  chicken/
  cow/
  dog/
  elephant/
  horse/
  sheep/
  spider/
  squirrel/
```

The image files are not included in this repository.
